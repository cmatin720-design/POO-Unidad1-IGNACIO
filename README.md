Sistema de Contenidos Audiovisuales



Descripción



Este es un proyecto hecho en Java con el propósito de practicar conceptos de programación orientada a objetos, como la herencia, la asociación y las relaciones entre clases.



Clases principales



ContenidoAudiovisual: es una clase abstracta que guarda los atributos que comparten todos los contenidos.



Pelicula: representa una película y permite agregarle actores.



SerieDeTV: representa una serie de televisión y permite agregarle temporadas.



Documental: representa un documental junto con su investigador.



Actor: guarda los datos de los actores.



Temporada: registra el número de temporada y cuántos episodios tiene.



Investigador: guarda el nombre y la especialidad del investigador.



VideoYouTube: representa un video de YouTube.



Cortometraje: representa un cortometraje.



Main: es la clase que ejecuta ejemplos para probar el sistema.



Cómo ejecutarlo



Clona o descarga este repositorio.



Importa el proyecto en Eclipse como proyecto existente.



Abre el archivo src/unidad1/Main.java.



Ejecuta la clase Main como una aplicación Java.



Funcionalidades



El sistema permite crear contenidos audiovisuales, mostrar sus detalles y establecer relaciones entre películas y actores, series y temporadas, y documentales e investigadores.



\## Validaciones

La clase Actor verifica que el nombre y la nacionalidad

no estén vacíos. Si alguno de estos datos es inválido,

se genera una excepción IllegalArgumentException.
